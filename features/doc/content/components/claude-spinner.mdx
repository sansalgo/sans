## Features

- Reverse-engineered from the Claude Code CLI binary — same glyph cycle and timing.
- Customizable colors via props or CSS variables, so it follows your theme.
- A single file styled with Tailwind CSS — no extra stylesheet.
- Elapsed time counter, plus optional token count and sub-status text.
- Respects `prefers-reduced-motion`, with a `reducedMotion` prop to force it either way.
