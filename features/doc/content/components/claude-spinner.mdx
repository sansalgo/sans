## Features

- Reverse-engineered from the Claude Code CLI binary — same glyph cycle, verb list, and color blending.
- Elapsed time and an auto-incrementing token counter, both overridable.
- Blends toward amber the longer a turn runs, and toward red when `stalled`.
- Respects `prefers-reduced-motion`, with a `reducedMotion` prop to force it either way.
